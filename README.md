# Elmiral – Releases

Installers for **Elmiral**, a 2D pixel-art fantasy action RPG for Windows (in development, not released).
This repository holds only the installers and the update manifest; the game's source code is not here.

- Latest installer: `Elmiral-0.1.1-Setup.exe`
- `latest.json` is read by the game's built-in updater (main menu → "Update available").
- Installing a new version over an existing one keeps your characters and settings
  (they live in `%APPDATA%\Elmiral`).
- The installer is not code-signed; Windows SmartScreen may show a warning.
